# Hidden Tally

Working-title GameFactoryLab release candidate for zero-cash discovery and rapid commercial signal testing.

## Mechanic

Remember the starting quantity, watch objects enter and leave a hidden box, then choose how many remain. Each 30-second run accelerates the cognitive load by increasing the number of in/out events per round.

This is intentionally different from the current active timing, catch/dodge, sequence-memory, spatial-transform, visual-tracking, midpoint-estimation and hidden-trajectory candidates. The core skill is continuous mental quantity tracking under visual motion.

## Commercial hypothesis

The mechanic is one-tap, language-light, mobile friendly, immediately understandable and naturally supports score challenges. It should be cheap to test because a complete build is a single self-contained HTML file with no remote runtime assets or backend.

Primary signal order:
1. completed 30-second runs
2. immediate replay rate
3. answer accuracy / streak depth
4. score-challenge shares and challenge opens

Do not spend additional production effort unless comparable free traffic shows stronger replay, session depth or sharing than weaker portfolio candidates. Use the same >=100 comparable-session hard kill/rework gate unless an external portal decides sooner.

## Controls

- Tap/click one of three answer buttons.
- Start/replay and share are normal buttons.
- No account or install required.
