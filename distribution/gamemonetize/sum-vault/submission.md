# Sum Vault — submission draft

## Short description
Select number tiles that add exactly to the vault target. Clear a 50-level deterministic puzzle campaign with three lives, hints and saved progress.

## Long description
Sum Vault is a fast touch-friendly number puzzle built around exact-sum combinations. Each level presents a target and a compact board of number tiles. Players can select any combination that reaches the target exactly, then attempt to unlock the vault. Wrong unlock attempts cost one of three lives, while hints reveal a useful move at a score penalty. Difficulty scales across 50 deterministic, always-solvable levels and progress is saved locally.

## Controls
- Touch / mouse: tap number tiles to select or deselect.
- Unlock Vault: checks the selected total.
- Hint: adds a seeded solution tile or removes one seeded distractor.
- Clear: removes the current selection.
