# Orbit Align — submission metadata

## Title
Orbit Align

## Short description
Rotate circular symbol rows until every column aligns, then clear a 40-level logic campaign.

## Long description
Orbit Align is a mobile-first logic puzzle built around reversible ring rotation. Each row behaves like a circular orbit: shift it left or right until matching symbols line up vertically across every row. The campaign contains 40 deterministic, always-solvable levels that expand from 3×5 layouts to dense 6×8 boards. Players have three lives per attempt, optional hints, local progress saving, score optimization, generated Web Audio feedback, and a level selector for unlocked stages.

## Instructions
Rotate any orbit left or right until every vertical column contains matching symbols, then press Check alignment. An incorrect check costs one life. Hint aligns one orbit but reduces the level score. Clear a level to unlock the next one.

## Controls
- Mouse / touch: use the left and right arrow buttons beside each orbit.
- Keyboard: number keys 1–6 rotate the corresponding orbit right; Shift + number rotates it left.
- Buttons: Check alignment, Hint, Restart.
