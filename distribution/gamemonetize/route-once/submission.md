# Route Once — submission copy

## Title
Route Once

## Short description
Visit every node exactly once without trapping the route. Forty deterministic graph puzzles scale from quick six-node boards to denser thirteen-node logic challenges.

## Description
Route Once is a mobile-first one-visit graph puzzle campaign. Each level starts at a fixed gold node. Move only along visible links and visit every node exactly once. A wrong branch can trap the route, so players need to look ahead, undo intelligently, and preserve three lives across increasingly dense graphs.

The campaign contains 40 deterministic, guaranteed-solvable levels. Progress saves locally, hints calculate a next move that still permits a complete solution, and result sharing is available after a clear. The game uses generated Web Audio and no paid or external art/audio assets.

## Controls
- Tap/click a connected unvisited node to extend the route.
- Tap the previous node or press Undo to step back.
- Restart Route resets the current path without consuming a life.
- Hint highlights one next node that keeps a full solution possible.
